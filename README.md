# Python

Repositório com projetos pessoais desenvolvidos em Python, reunidos como forma de estudo, prática e experimentação com diferentes ideias e tecnologias.

## 📁 Estrutura

```
Python/
└── PROJETOS/
    ├── projeto-1/
    ├── projeto-2/
    └── projeto-3/
```

Cada subpasta dentro de `PROJETOS/` contém um projeto independente, com seu próprio código-fonte e, quando aplicável, suas próprias dependências e instruções de uso.

## 🔧 Como usar

Para rodar algum dos projetos, entre na pasta correspondente e siga as instruções do próprio projeto (se houver um README específico) ou execute o script principal:

```bash
cd PROJETOS/nome-do-projeto
python main.py
```

Caso o projeto possua dependências específicas, instale-as com:

```bash
pip install -r requirements.txt
```

## 🛠️ Tecnologias

- Python 3.x
